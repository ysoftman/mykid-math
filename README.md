# 준영이의 수학공부

> **생각하는 초등 5·6학년 수학 개념 연구소 & 무한 문제 풀이 웹 앱**

공식만 단순 암기하는 수학이 아닌, **직접 눈으로 보고 손으로 조작하며 원리를 깨치는 시각적 인터랙티브 수학 학습 플랫폼**입니다.

---

## ✨ 핵심 기능 소개

### 1. 🧪 시각적 인터랙티브 개념 실험실 (Lab)

- **약수와 배수 탐색기**:
  - $N$개의 타일을 가로×세로로 조합하여 직사각형을 완성해보며 약수의 의미를 체득
  - 두 수의 공약수, 최대공약수(GCD) 및 최소공배수(LCM) 시각 비교
- **분수 연산 실험실**:
  - 분모가 서로 다른 두 분수를 공통분모(최소공배수) 눈금으로 쪼개어 통분되는 과정을 슬라이더로 체험
  - 가로×세로 2차원 면적 모델로 분수의 곱셈 시각화
- **소수 격자 & 자릿수 실험실**:
  - 100칸(10×10) 모눈종이에서 가로×세로 색칠 겹침을 통해 소수 곱셈과 소수점 위치 원리 파악
- **도형과 원의 넓이 실험실**:
  - 삼각형 2개를 합쳐 평행사변형(밑변×높이) 만들기 애니메이션을 통해 **'÷ 2'** 원리 이해
  - 사다리꼴 2개를 엇갈려 붙여 큰 평행사변형으로 변형
  - 원을 8·16·32등분 피자 모양으로 잘라 직사각형으로 이어붙여 $\text{반지름} \times \text{반지름} \times 3.14$ 공식 유도
- **비와 비율 칵테일 믹서**:
  - 딸기 시럽과 탄산수의 양을 조절하며 농도 색상과 백분율(%) 변화 관찰

---

### 2. 🎯 무한 랜덤 문제 풀이 & 친절한 단계별 해설

- **무한 문제 생성**: 난이도별(하 / 중 / 상) 무한 랜덤 문제 출제
- **다양한 문제 유형**: 단답형 연산 문제부터 실생활 문장제(스토리텔링) 문제까지 수록
- **편리한 입력기**: 분수 답안(분자/분모) 및 실수 답안 입력기 제공
- **즉시 채점 & 사운드 피드백**: 정답 시 신나는 팡파레와 Confetti 파티클 효과
- **친절한 단계별 해설**: 막히거나 틀렸을 때 1단계, 2단계, 3단계 풀이 과정 표시

---

### 3. 🗺️ 성장 로드맵 & 오답 복습 노트

- **레벨업 & 별(⭐) 시스템**: 정답을 맞힐 때마다 별을 모아 Lv.1 탐험가에서 Lv.5 수학 마스터로 성장
- **도전 과제 뱃지**: 단원별 마스터 뱃지 및 첫 정답 뱃지 수집
- **오답 노트 자동 수집**: 틀린 문제는 자동으로 오답 노트에 저장되며 언제든 재도전 가능

---

### 4. ✏️ 전자 칠판 / 수학 연습장 (ScratchPad)

- 아이들이 문제 풀이 중 종이를 찾지 않아도 화면 상에서 바로 계산할 수 있는 플로팅 캔버스
- 마우스 및 태블릿 터치 필기, 펜 색상/굵기 조절, 지우개 지원

## 🚀 시작하기

### 실행 방법

```bash
# 1. 의존성 설치 (최초 1회)
bun install

# 2. 로컬 개발 서버 실행
bun run dev

# 3. 브라우저에서 접속
# http://localhost:5173
```

### 프로덕션 빌드

```bash
bun run build
bun run preview
```

- **상태 보존**: Browser LocalStorage

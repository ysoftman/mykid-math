# 준영이의 수학공부

> **생각하는 초등 5·6학년 수학 개념 연구소 & 무한 문제 풀이 웹 앱**

공식만 단순 암기하는 수학이 아닌, **직접 눈으로 보고 손으로 조작하며 원리를 깨치는 시각적 인터랙티브 수학 학습 플랫폼**입니다.

---

## ✨ 핵심 기능 소개

### 1. 🧪 시각적 인터랙티브 개념 실험실 (Lab)

- **약수와 배수 시각화 실험실**:
  - $N$개의 타일을 가로×세로로 조합하여 직사각형을 완성해보며 약수의 의미를 체득
  - 두 수의 공약수·공배수로 최대공약수와 최소공배수를 비교하고, 공약수로 계속 나누어 구하기
- **분수 시각화 실험실**:
  - 분모가 서로 다른 두 분수를 공통분모(최소공배수) 눈금으로 쪼개어 통분하고, 합·크기 비교·나눗셈을 슬라이더로 체험
  - 가로×세로 2차원 면적 모델로 분수의 곱셈 시각화
- **소수 격자 & 자릿수 실험실**:
  - 100칸(10×10) 모눈종이에서 가로×세로 색칠 겹침을 통해 소수 곱셈·나눗셈과 소수점 위치 원리 파악
- **도형과 원의 넓이 실험실**:
  - 삼각형 2개를 합쳐 평행사변형(밑변×높이) 만들기 애니메이션을 통해 **'÷ 2'** 원리 이해
  - 사다리꼴 2개를 엇갈려 붙여 큰 평행사변형으로 변형
  - 마름모를 두 대각선을 가로·세로로 하는 직사각형으로 둘러싸 그 절반이 넓이임을 확인
  - 원을 8·16·32등분 피자 모양으로 잘라 직사각형으로 이어붙여 $\text{반지름} \times \text{반지름} \times 3.14$ 공식 유도
- **합동과 대칭 모양 연구실**:
  - 도형을 옮기고 뒤집고 180° 돌려 합동과 대응점·대응변·대응각을 확인
  - 대칭축을 따라 접는 선대칭과 중심을 기준으로 돌리는 점대칭을 시각화
- **소수의 곱셈 자릿수 실험실**:
  - 두 소수를 골라 자연수 곱 → 소수점 아래 자리 수 더하기 → 소수점 찍기 순서로 곱 구하기
  - 고른 소수에 10·100·0.1·0.01을 곱하며 곱의 소수점 위치가 옮겨지는 규칙 확인
- **직육면체와 정육면체 연구실**:
  - 겨냥도로 면·모서리·꼭짓점 개수와 평행·수직인 면을 알아보고, 슬라이더로 바뀌는 겨냥도에서 모서리 길이의 합·부피·겉넓이 확인, 전개도 살펴보기
- **평균과 가능성 실험실**:
  - 점수를 바꾸며 평균 = 자료 값의 합 ÷ 자료의 수와 평균보다 높은 과목 수 확인, 회전판으로 가능성을 말과 수(0, 1/2, 1)로 나타내기
- **비와 비율 실험실**:
  - 딸기 시럽과 탄산수의 양을 조절하며 진하기 색상과 비율·백분율(%) 변화 관찰
  - 비 읽기(전항·후항), 같은 맛으로 2배 만들기(비의 성질·비례식), 많은 양의 주스를 비례배분하기

### 2. 🎯 무한 랜덤 문제 풀이 & 친절한 단계별 해설

- **무한 문제 생성**: 난이도별(하 / 중 / 상) 무한 랜덤 문제 출제
- **다양한 문제 유형**: 단답형 연산 문제부터 실생활 문장제(스토리텔링) 문제까지 수록
- **도형 그림 문제**: 합동과 대칭 퀴즈에 도형 그림과 대응변 길이·대응각 크기를 표시
- **편리한 입력기**: 분수 답안(분자/분모) 및 소수 답안 입력기 제공
- **즉시 채점 & 사운드 피드백**: 정답 시 신나는 팡파레와 Confetti 파티클 효과
- **친절한 단계별 해설**: 막히거나 틀렸을 때 1단계, 2단계, 3단계 풀이 과정 표시
- **수학 게임**: 60초 타임어택, 단원 보스전, 친구 대결, 알뜰 장보기

---

### 3. 🗺️ 성장 로드맵 & 오답 복습 노트

- **레벨업 & 별(⭐) 시스템**: 정답을 맞힐 때마다 별을 모으고, 별 10개마다 레벨이 오르는 수학 탐험가로 성장
- **도전 과제 뱃지**: 단원별 뱃지와 첫 정답·연속 정답·오답 정복·출석·게임 등 업적 뱃지 수집
- **오답 노트 자동 수집**: 틀린 문제는 자동으로 오답 노트에 저장되며 언제든 재도전 가능
- **오늘의 미션 & 상점**: 매일 도전 퀴즈 미션과 출석 도장, 모은 별로 캐릭터·꾸미기·게임 아이템 구입

- 마우스 및 태블릿 터치 필기, 펜 색상/굵기 조절, 지우개 지원

## 🚀 시작하기

### 실행 방법

```bash
# 1. 의존성 설치 (최초 1회)
bun install

# 2. 로컬 개발 서버 실행
bun run dev

# 3. 브라우저에서 접속
# http://localhost:5173
```

### 프로덕션 빌드

```bash
bun run build
bun run preview
```
